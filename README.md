# Pestinha (versão FacincaniTech)

Pets de tela que vivem no seu monitor, cada um com o próprio cérebro (rede neural pulsada).
Esta é uma versão modificada do [Pestinha original](https://github.com/mille-okws/pestinha),
distribuída sob a mesma licença (GNU GPL v3 ou posterior).

O que esta versão acrescenta: desenhos que evoluem, casinha, consciência de existir,
personas, moedas, loja, joguinhos e a rede social dos pestinhas.

Site: https://facincanitech.github.io/pestinha/
